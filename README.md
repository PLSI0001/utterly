# Utterly - Frontend Design Showcase

A modern, responsive React application showcasing the user interface and design of Utterly - an AI-powered voice processing platform.

## 🎨 Features Showcased

- **Landing Page** - Modern hero section with animated elements
- **Authentication Pages** - Clean login/signup interface
- **Dashboard** - Voice processing interface with metrics
- **Browser Extension** - Chrome extension popup design
- **Responsive Design** - Mobile-first approach with Tailwind CSS

## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. **Open your browser:**
   Navigate to `http://localhost:3000`

## 🛠 Tech Stack

- **Frontend Framework:** React 19
- **Styling:** Tailwind CSS 4
- **Routing:** React Router DOM
- **Icons:** Lucide React + React Icons
- **Animations:** Motion (Framer Motion)
- **Charts:** Recharts
- **Build Tool:** Vite

## 📂 Project Structure

```
src/
├── components/         # Reusable UI components
├── pages/             # Main application pages
├── lib/               # Utilities and configurations
└── assets/            # Static assets
extension/             # Chrome extension files
```

## 🎯 Purpose

This is a **frontend-only showcase** demonstrating the user interface design and user experience of the Utterly platform. All backend functionality has been mocked for demonstration purposes.

## 🔧 Development

- **Build:** `npm run build`
- **Preview:** `npm run preview`
- **Lint:** `npm run lint`
